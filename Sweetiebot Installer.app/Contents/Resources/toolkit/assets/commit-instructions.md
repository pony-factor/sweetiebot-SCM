# Sweetiebot commit instructions

Commit titles should start with one professional emoji that matches the change type, followed by a space and a concise imperative title.

Choose the emoji using the first matching rule below:
- Bug fixes in code: use one of 🐛 🐜 🐝 🐞 🦗 🕷️ 🦟. Pick one for the first bug fix on a branch and keep using that same bug emoji for later bug-fix commits on that branch.
- Stellar decentralized-exchange work: 💱
- Soroban or Stellar smart-contract work: 🧮
- Work specifically about decentralization: 🌐
- Financial-inclusion policy: 🌍, 🌎, or 🌏
- Free-market economics: 📈
- Frontend interpreted style preferences: 🖌️
- Frontend color styling: 🎨
- Image modifications: 🖼️
- Brand display schemes: ✨
- Responding to pull-request feedback from a real person: 🤝
- Syncing a branch to main: use the exact title `🔄 Sync brach to main`
- Code comments: 💬
- Scribble-style notes: 💭
- Freedom policy: 🕊️
- Freedom-related code: 🦅
- General policy: ⚖️
- United States policy: 🗽
- Refactoring blocks: 🏗️
- Major configuration metrics: ⚙️
- Parameter tuning: 🔧
- Connecting functions: 🔩
- Making equivalent code more concise: 🗜️
- Package configuration changes: 🧰
- Superstonk or the GameStop ape investor movement: 🦍
- My Little Pony fandom material in a private repository: 🦄
- Math formulas or calculations: 🧾
- Deleting files: 🗑️
- Consolidating material into one place: 🗃️
- Reorganizing many files: 🗂️
- Creating an archive: 🗄️
- Adding a directory: 📂
- Deleting a directory: 📁
- Drafting new prose from scratch: ✒️
- Revising existing prose: 🖋️
- Grammar- or structure-only prose revisions: 🖊️
- Adding a footnote: ✏️
- Adding a rough standalone reference or URL: 🖍️
- Revising multiple whole sections in a large diff: 📝
- Creating an almost-empty placeholder file: 🌱
- Adding a network call: 📡
- Tests, scoping, or security work: use one appropriate symbol from 📌 📍 📎 🖇️ 📏 📐 ✂️ 🧷 🔒 🔓 🔏 🔐 🔑 🗝️ 🔨 🪓 ⛏️ ⚒️ 🛠️ 🧲 🛡️ 🦯 🔗 ⛓️ ⚗️ 🧪 🧬 🔬 🔭 💊 🩹

Write the subject as a concise command describing the actual staged change. Do not infer work that is not present in the diff.

When committing directly to main, include a short body sentence that says specifically what the commit changes so later readers can understand it.

Do not add co-author trailers, signatures, or other metadata to generated text; Sweetiebot handles those separately.
